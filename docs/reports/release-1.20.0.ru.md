# Проверка 1.20.0

Дата: 13 сентября 2026 года.

## Что входит

Гостевые вызовы, личная панель релиза, копирование названия и ссылки, остановка
поиска с сохранением найденного, агрегированная статистика inline и отдельная
обработка радиошоу Apple Music. Основное оформление карточек из 1.19.2 сохранено.

## Проверено перед выпуском

- 867 тестов и 104 подтеста; покрытие с учётом ветвлений — 77% при пороге 72%.
- Ruff, Pyflakes, Bandit, компиляция и Mypy для четырёх типизированных модулей.
- Согласованность зависимостей; pip-audit не обнаружил известных уязвимостей.
- Установочный пакет 1.20.0: импорт, контракт публикации, переводы, изображения
  и лицензия проходят проверку.
- Публичная страница The Alligator Hour действительно возвращает сведения о
  радиошоу. Карточка использует исходный регион ссылки и тег `#radio`.
- Отмена между экземплярами сервера, изоляция одинаковых поисков, новый запрос
  во время отмены старого, сохранение частичного результата и повторное
  использование сообщения прогресса проверены управляемыми асинхронными тестами.
- Гостевой ответ, неоднозначный поиск, однократная отправка при сетевой ошибке,
  личная панель без изменения общей карточки, копирование и дедупликация
  inline-событий проверены с имитацией Telegram API.

## Границы проверки

Гостевой вызов требует Guest Mode в BotFather. Статистика отправок требует
`/setinlinefeedback`; при выборке меньше 100% учитываются только полученные события.
Переключатели BotFather не включаются самим обновлением кода.

У inline-callback нет адреса чата, поэтому inline-кнопка «О релизе» открывает
личный чат. Общая панель содержит только сведения о релизе и ссылки, хранится
до 180 дней. Очень длинное название не получает кнопку копирования из-за
лимита Telegram. Подробности — в [настройке](../SETUP.ru.md#возможности-telegram-120).

Визуальная проверка новых панелей в настоящих клиентах Telegram и отправки
в тестовый чат в эту локальную проверку не входят. Production canary проверяет
версию, инфраструктуру и контракт сообщений без отправки публикаций; затем
обновляет подписки webhook. Provider canary проверяет публичные источники,
включая радиошоу Apple Music, отдельно от решения об откате.
