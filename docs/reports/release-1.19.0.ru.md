# Выпуск 1.19.0 — рабочий экран и надёжность

12 сентября 2026. Основа изменений — 1.18.2 (`081cd66`).

## Что изменилось

Карточка получила пять основных действий: изменить, добавить в подборку,
посмотреть результат, сохранить и отправить. Текст, теги, обложка и кнопки
находятся на первом экране редактирования. «Мои посты» открывает библиотеку
с поиском и фильтрами; непустая подборка видна на главном экране.
Обычные черновики живут 7 дней после правки, сохранённые — 90 дней,
до 30 сохранений. Истёкшие записи освобождают лимит.

Подборка сохраняет полный список и порядок до десяти позиций. Выбор позиции
открывает перемещение, замену, удаление и заметки. Старые позиционные кнопки
обновляют список. Новые ссылки во время ввода текста получают выбор назначения.
При повторе частичного поиска сохранённые успешные результаты используются
повторно, а запросы уходят только к неудачным источникам.

## Исправленные риски

| Сценарий | Поведение 1.19 |
| --- | --- |
| Одновременная запись с двух серверов | Атомарное сравнение версий; независимые изменения сессии объединяются, конфликт отклоняется |
| Кнопка от старой карточки | Обновление до текущей версии без применения устаревшего действия |
| Сбой Redis при сохранении | Успех не показывается до подтверждения записи |
| Неизвестный результат ручной отправки | Сохранённое намерение доставки блокирует слепой повтор; владелец сначала проверяет чат |
| Замена публикации | Старый пост удаляется после подтверждения новой публикации |
| Новая подборка во время правки подводки | Существующая подборка сохраняется |
| Произвольный ручной тег | Не превращается в подтверждённый общий жанр |
| Очень длинная карточка | Сокращённый вид редактора в пределах Telegram; исходный текст сохраняется |
| Устаревшее сохранение после удаления сессии | Не восстанавливает удалённую сессию |

Исходная аватарка, inline-режим, публичные кнопки с эмодзи и полный список
подборки сохранены. Обновлены RU/EN-тексты и документация.

## Проверки выпуска

- Python 3.12: 826 тестов и 104 подтеста; покрытие с ветвлениями выше порога 72%.
- 33 новые регрессионные проверки. Модель 100 параллельных пользователей,
  1 200 операций добавления: данные пользователей разделены, каждая подборка
  ограничена десятью уникальными позициями.
- Ruff, форматирование, Pyflakes, Bandit и согласованность зависимостей.
- Mypy: четыре настроенных модуля, не весь проект.
- `pip-audit`: известных уязвимостей runtime-зависимостей на дату проверки не найдено.
- Генератор макета с реальными текстами и клавиатурами бота.
- Проверка потенциальных секретов в публикуемых исходниках.

Устанавливаемый пакет проверяется перед публикацией: импорты из wheel,
контракт публикаций, RU/EN-каталог, контрольная сумма оригинальной аватарки,
лицензия и соответствие исходному commit. Итоговые артефакты, точное покрытие,
проверки GitHub и сервера фиксируются в
[релизе 1.19.0](https://github.com/StonerHand/stonerhand-soundlinks-bot/releases/tag/v1.19.0).

## Ограничения проверки

Модель параллельного доступа проверяет логику, а не пропускную способность
реального Redis или Telegram. Реальная отправка в тестовый чат и проверка
клиентов iOS/Android/Desktop не выполнялись: отдельный тестовый чат не настроен.
Открытие локального HTML браузером заблокировано политикой доступа; макет
сгенерирован, но визуальная проверка через браузер не выполнена.

Отмена удаления позиции из подборки по-прежнему ограничена 15 секундами
и памятью текущего процесса; пятиминутная отмена оформления хранится в черновике.
Проверки не гарантируют полного отсутствия ошибок. Сценарии реального клиента
перечислены в [чек-листе](../RELEASE_CHECKLIST.ru.md).
