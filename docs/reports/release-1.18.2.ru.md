# Ревью и финальная сборка 1.18.2

11 сентября 2026. Исходная версия ревью — `15de17d` (1.18.1).

Проверен путь «ссылка или поиск → редактор → сохранение → отправка/очередь»,
inline-публикации, ограничения Telegram, права владельца, входящий webhook,
загрузка обложек и состав Python-пакета. Отменённое разделение `bot.py`
не возвращалось. Оформление, оригинальная аватарка и полный список подборок сохранены.

## Найдено и исправлено

| Приоритет | Проблема | Исправление и доказательство |
| --- | --- | --- |
| Высокий | Тёплый сервер использовал старые черновики, настройки и подборки после правки на другом сервере | Redis стал источником актуального состояния. Сессия кэшируется внутри одного update. Проверки двух рабочих процессов воспроизводили потерю правок до исправления и проходят после него. |
| Высокий | Сбой записи Redis мог выглядеть как успешное сохранение | Подтверждённые записи черновиков, сессий, подборок и шаблонов; явная ошибка вместо ложного успеха. Проверки отключённого хранилища проходят. |
| Высокий | При недоступном Redis блокировка публикации переходила в локальную память | Отправка не получает блокировку при отказе общего хранилища. Проверка предыдущей публикации также не принимает сетевую ошибку за отсутствие поста. |
| Средний | Переполненная подборка могла пометить одиннадцатую позицию как уже добавленную | Показывается сообщение о лимите, состав и признак добавления остаются корректными. |
| Средний | Необязательная рамка скачивала обложку с произвольного адреса метаданных | Разрешены только CDN музыкальных обложек, как у коллажей. Локальные адреса и поддельные суффиксы отклоняются до HTTP-запроса. |
| Средний | Минимальный setuptools не поддерживал используемый строковый формат лицензии | Требование поднято до 77.0.3, лицензия явно включена. Готовый wheel проверяется отдельно от исходников, в том числе в CI. |

Обоснование версии сборщика: [официальная документация setuptools о PEP 639](https://setuptools.pypa.io/en/stable/userguide/license_migration.html).

## Проверки сборки

- Python 3.12: **793 теста и 104 подтеста**, все проходят.
- Покрытие с ветвлениями: **76,42%**, установленный порог — 72%.
- Ruff, форматирование, Pyflakes, Bandit, компиляция и согласованность зависимостей.
- Настроенный Mypy: четыре модуля, ошибок нет; это не полная типизация проекта.
- `pip-audit`: известных уязвимостей в runtime-зависимостях и их зависимостях
  на дату проверки не найдено.
- Готовый wheel: импорт модулей непосредственно из архива, контракт публикаций,
  RU/EN-каталог, контрольная сумма исходной аватарки и наличие MIT-лицензии.
- Исходный архив включает API, документацию, сценарии, тесты и их данные;
  `.env`, токены и локальные данные в релиз не включаются.

## Границы проверки

Локальный live-тест MusicBrainz и зависимого от него обогащения поиска не прошёл.
Проверка провайдеров из GitHub выполняется отдельно и отражает доступность
из его окружения. При недоступном источнике сохраняются только подтверждённые
ссылки; неподтверждённая Spotify-ссылка не добавляется.

Реальные отправки тестовых сообщений и визуальная проверка Telegram
на iOS/Android/Desktop в этом выпуске не выполнялись: отдельный тестовый чат
не настроен в доступном окружении. Нагрузочное испытание также не проводилось.
Список ручных сценариев — в [чек-листе](../RELEASE_CHECKLIST.ru.md).
Автотесты и успешный запуск не являются доказательством полного отсутствия ошибок.
