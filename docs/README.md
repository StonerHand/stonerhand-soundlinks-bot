## Карта репозитория

```text
api/                    Webhook, диагностика и очередь Vercel
src/music_links_bot/    Код бота, исходная аватарка и переводы
tests/                  Тесты, контракты и проверки рабочего сервиса
scripts/                Генератор локального просмотра интерфейса
docs/                   Руководства, оформление README и архив отчётов
.github/                CI, плановые проверки и обновление зависимостей
```

`pyproject.toml` описывает Python-пакет и инструменты разработки;
`requirements.txt` нужен сборке Vercel. Их зависимости синхронизируются тестом.
`vercel.json` задаёт маршруты и резервное расписание. Это рабочие части проекта.

## Отчёты прошлых проверок

Отчёты фиксируют состояние на указанную дату. Текущий статус смотрите в
[GitHub Actions](https://github.com/StonerHand/stonerhand-soundlinks-bot/actions).

- [Проверка качества 1.15.3](reports/quality-1.15.3.ru.md).
- [Теги, подборки и оформление 1.17.0](reports/ui-1.17.0.ru.md).

Локальный просмотр интерфейса создаётся командой
`python scripts/render_ui_preview.py` из корня установленного проекта.
Откройте `output/ui-preview/index.html`; действия в нём имитируются.
Сгенерированный просмотр, логи, секреты и временные данные не хранятся в Git.
