# Обновление StonerHand: интерфейс и оформление

Локальная проверка перед выпуском 1.16.0 от 8 сентября 2026.
Результат публикации проверяется отдельно по версии и commit рабочего бота.

[Открыть интерактивный просмотр](output/ui-preview/index.html)

Просмотр собирается из текстов и клавиатур бота командой
`python scripts/render_ui_preview.py`. В нём можно переключать экраны,
светлую и тёмную тему, ширину окна и переходить по кнопкам.
Отправка и изменение настроек в просмотре имитируются.

## Что изменилось

| Область | Результат |
| --- | --- |
| Аватарка | Использован твой исходный PNG с когтистой рукой. Файл сохранён без изменения байтов. |
| Первый запуск | Короткое приветствие с аватаркой, пример и создание первой карточки. Полное меню появляется после создания карточки. |
| Редактор | Отдельные разделы «Оформление», «Текст», «Кнопки площадок». Подразделы возвращают на родительский экран. |
| Карточка | Жирный артист, название отдельной строкой, меньше служебных значков. Исходные обложки релизов сохранены. |
| Отправка | Отдельное меню назначения: себе, в канал или по расписанию. Публикация в канал по-прежнему требует явного подтверждения. |
| Планирование | Доступно прямо на карточке администратора. Точные даты и время, указанный часовой пояс и собственная дата. |
| Защита от ошибок | Прошедшее время отклоняется. Повторный выбор того же времени для той же карточки не создаёт дубликат в очереди. |
| Результат публикации | Название, канал, дата и действие «Открыть пост». |
| Библиотека | До 30 доступных черновиков, по пять на страницу; названия и статусы. Недавние релизы тоже листаются. |
| Настройки | RU/EN, оформление новых карточек и режим хэштегов сохраняются между перезапусками отдельно для каждого пользователя. |
| Подборки | Сохранён Classic-вид и существующие коллажи из оригинальных обложек. |

Чёрно-бело-бирюзовая палитра используется в фирменном изображении и файле
просмотра. Цвет сообщений, шрифт, размеры и поддержка цветных кнопок в самом
Telegram зависят от клиента и темы пользователя.

## Проверка

- Полный локальный набор: **734 теста и 95 подтестов прошли**.
- Покрытие с учётом ветвлений: **75,32%**, установленный порог — 72%.
- Проверки стиля, форматирования, импортов, типов в настроенных модулях,
  статического анализа безопасности, совместимости зависимостей и компиляции
  прошли. Проверены полнота RU/EN-переводов и одинаковое содержимое аватарки.
- Новые сценарии проверяют сохранение настроек после перезапуска, изоляцию
  языков при параллельных запросах, чужие и удалённые черновики, страницы
  библиотеки, отменённую очередь, точное время и повторные нажатия.
- Пакет бота собран: в нём проверены исходный файл аватарки и модуль настроек.
  Файл просмотра содержит 29 экранов; его JavaScript прошёл проверку синтаксиса.

## Что ещё не подтверждено

Встроенный браузер заблокировал открытие локального HTML-файла. Поэтому
визуальная проверка этого просмотра в браузере не подтверждена. Не проводились
новая реальная отправка в Telegram и проверка на iOS, Android и Desktop.
Этот документ описывает локальную проверку и сам по себе не подтверждает развёртывание.
