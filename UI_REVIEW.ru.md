# StonerHand 1.17.0: теги, подборки и оформление

Локальная проверка от 9 сентября 2026 года перед выпуском.

[Интерактивный просмотр](output/ui-preview/index.html) собирается из реальных
текстов и клавиатур: `python scripts/render_ui_preview.py`. В нём доступны
настройки сетки, группировки и обложки, саундтрек, видео и десять позиций.
Отправка и изменение данных в просмотре имитируются.

## Результат

| Область | Изменение |
| --- | --- |
| Автотеги | Тип публикации имеет приоритет. Различаются трек, альбом, EP, сингл, официальный сборник, саундтрек, авторская подборка и видео. До пяти нормализованных тегов без дублей. |
| Жанры | Подтверждённые сведения конкретного релиза. Для подборки жанр должен соответствовать всем музыкальным позициям. Противоречия и неполные данные не дают случайный жанровый тег. |
| Исправления | Переключатели отдельных тегов, добавление своих, запоминание для релиза, сброс к автоматическим тегам. До 60 последних исправлений отдельно для пользователя. |
| Названия | Удалены служебные подписи Spotify. Сохранены саундтреки, концертные версии и ремастеры. Подтверждённые формат, год и количество треков показаны отдельно. |
| Тип карточки | Обычный релиз: артист → название. Various Artists: название → сведения. Видео: название записи → источник, без подмены исполнителя автором канала. |
| Подборка | Полный нумерованный список, точный состав, исходный порядок, разделы по артистам/альбомам или вручную, заметки к позициям. Название сохраняется при inline-отправке. |
| Кнопки | Ясные подписи без декоративных кружков, один главный акцент, объединение одинаковых адресов. Номера совпадают со списком, длинные подписи занимают отдельный ряд. |
| Сетка | Сохраняемые «Одна колонка / Авто / Компактно». До десяти позиций остаются одним постом. При превышении лимита сначала сокращаются заметки, все позиции сохраняются. |
| Обложка | Выбор чистого исходного арта или превью площадки. YouTube сохраняет видеопревью. Исходная аватарка с когтистой рукой не изменена. |
| Надёжность | Настройки изолированы между пользователями и конкурентными запросами. Inline-результаты обновляются сразу; сохранённые теги входят в снимок черновика для доставки. |

## Проверка

- **769 тестов и 95 подтестов прошли**, включая 35 новых проверок.
- Покрытие с учётом ветвлений — **75,65%**, порог проекта — 72%.
- Проверены стиль, импорты, форматирование, типы в настроенных модулях,
  статический анализ безопасности, согласованность зависимостей и компиляция.
- Проверены перезапуск, чужие и поддельные кнопки, превышение лимита тегов,
  конфликтующие жанры, HTML, перестановка заметок, длинные названия и emoji,
  сохранение названия и изменение inline-результата при переключении сетки.
- Проверка публикаций расширена до 11 сценариев, включая саундтрек Scott Pilgrim
  и все три сетки на десяти позициях; этот же отчёт доступен в рабочем боте.
- Собран пакет 1.17.0. SHA-256 исходной аватарки:
  `70d5305a867efdf4ddbff8a08c3f79dbd93bff6ee1bced9c9db13d75d550d3e5`.
- JavaScript локального просмотра прошёл проверку синтаксиса.

## Границы проверки

Управление доступным клиентом Telegram вернуло `AXError.notImplemented`;
полный визуальный сценарий новых экранов не подтверждён. Встроенный браузер
ранее заблокировал локальный HTML. Цвета, шрифты и высота кнопок зависят
от клиента и темы Telegram; длинная подпись может обрезаться самим клиентом.
Этот документ фиксирует локальные проверки; выпуск подтверждается отдельно
по commit, состоянию Vercel и проверкам рабочего бота.
