## Исправления

| Область | Найденная проблема | Новое поведение |
| --- | --- | --- |
| Проверка секретов | Не-ASCII строка могла вызвать исключение вместо отказа в доступе | Общая проверка сравнивает байты; некорректные строки и отсутствующий секрет отклоняются |
| Коллажи | Некорректная подпись могла завершить запрос ошибкой сервера | Подпись проверяется безопасно; payload должен быть ASCII и укладываться в лимит |
| Брендирование | Обложка скачивалась целиком без ограничения объёма | Потоковая загрузка до 3 МиБ на изображение, проверка типа ответа, без переходов по redirect |
| Обработка картинок | Большое изображение могло потребовать чрезмерно много памяти | До декодирования проверяются 12 млн пикселей, ограничен размер результата, изображения закрываются |
| Медленные источники | Постепенная отдача данных могла надолго удержать обработчик | Общий бюджет загрузки обложки и логотипа — 8 секунд; при сбое остаётся обычная обложка |
| Черновики | Старые кнопки и ответы на старые запросы ввода могли менять удалённую карточку | Удалённый черновик доступен только для восстановления; остальные действия отклоняются с объяснением |
| Права редактора | Callback без владельца проходил проверку собственности | Для действия требуется пользователь — владелец черновика |
| Публикация | «Опубликовать», «Повторить» и «Заменить» имели разные блокировки одного черновика | Эти действия используют общую блокировку |
| Блокировки | Отмена во время показа занятости оставляла блокировку; старый владелец мог снять новую | Освобождение выполняется при отмене и проверяет владельца; заполнение таблицы не вытесняет активную блокировку |
| Проверка прав канала | Временная сетевая ошибка кэшировалась на пять минут | Ошибка не кэшируется; следующая попытка заново проверяет права |
| MusicBrainz | Отмена одного ожидания отменяла общий запрос других пользователей | Независимая отмена ожиданий, общий запрос продолжает работать |

## Интерфейс

- Чистое «Превью» доступно прямо на карточке, без перехода в дополнительные действия.
- Очередь показывает статус отправки и скрывает недоступную отмену активного задания.
- Отмена запланированного поста показывает название и требует подтверждения.
- Повтор неоднозначной отправки сначала предлагает проверить канал, затем явно подтвердить, что пост отсутствует.
- На средней странице очереди больше нет ряда из трёх кнопок; навигация подписана словами.
- Повторное обновление неизменившейся очереди не считается ошибкой Telegram.
- Новые тексты доступны на русском и английском. Сохранена одна основная кнопка в карточке и не более двух кнопок в строке очереди.

## Проверки

- Python 3.12: **721 тест и 87 подтестов**, все прошли; покрытие с учётом ветвлений — **75%**.
- Добавлены проверки некорректных секретов, лимитов загрузки и декодирования, отмены задач, конкурирующих действий, старых кнопок и подтверждений очереди.
- Проверки Ruff, форматирования, Pyflakes, Bandit, компиляции, согласованности зависимостей и настроенный Mypy прошли. Mypy в этом проекте охватывает четыре модуля, а не весь код.
- `pip-audit` не нашёл известных уязвимостей в зависимостях из `requirements.txt` и их зависимостях на момент проверки.
- Проверен diff снимков интерфейса: изменились только добавленная кнопка превью и соответствующий релизный UI-контракт.
- Действующий production прошёл read-only проверку `/api/health`, `/api/collage?health=1` и `/api/smoke`. Это проверка существующей версии, а не развёртывание новых изменений.
- Живая проверка провайдеров прошла для Spotify, SoundCloud, YouTube, импорта Apple Music и NTS. Подтверждение Spotify через MusicBrainz не прошло: отдельная диагностика показала `ConnectTimeout`. Соответствующая проверка полного обогащения текстового поиска тоже не прошла.

## Ограничения

Сбой соединения с MusicBrainz из текущего окружения не устранён изменением кода: при его недоступности резервная карточка сохраняет подтверждённую Apple Music-ссылку. Это не означает отказ всего поиска или прямых Spotify-ссылок.

Реальные отправки новых экранов и публикаций в Telegram, внешний вид на iOS/Android/Desktop, нагрузочное испытание и новая матрица Python 3.10/3.11 в этой локальной проверке не выполнялись. Исчерпывающего доказательства отсутствия ошибок или уязвимостей эти проверки не дают.

Технические основания ограничений: [Python — безопасное сравнение секретов](https://docs.python.org/3/library/hmac.html#hmac.compare_digest), [HTTPX — потоковые ответы](https://www.python-httpx.org/quickstart/#streaming-responses), [Pillow — открытие изображений и ограничения декодирования](https://pillow.readthedocs.io/en/stable/reference/Image.html#PIL.Image.open).
